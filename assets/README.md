# assets

Reference material only — **not** shipped with the site. The actual production
art the app renders lives in `src/assets/svg/` (see `docs/flower-art-guide.md`).

- `brand assets/` — the real Everbloom logo, business card, and brand colors,
  used as the reference when building `src/assets/svg/decorative/logo-mark.svg`
  and `src/styles/tokens.css`.
- `inspiration/` — screenshots of the reference product ("Digibouquet") whose
  *flow* this app follows (see the project brief / plan for what's kept vs.
  intentionally changed).
