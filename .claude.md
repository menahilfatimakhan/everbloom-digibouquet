# Everbloom Digibouquet — Project Notes

## Overview
A digital bouquet builder for the floral small business Everbloom by Meena. Full product brief and locked decisions are in the plan history; see `docs/architecture.md` for the technical design as-built.

## Stack
Astro (server output, `@astrojs/vercel` adapter) + framework-free TypeScript for the interactive builder (`src/builder/`) + GSAP/Lenis for animation. No UI framework — deliberate, for handoff simplicity to a non-framework-expert owner.

## Structure
- `src/pages/` — routes (landing, `/build`, `/r/[id]`, `api/links*`)
- `src/builder/` — state store, procedural bouquet composition (`layoutEngine.ts`), the four builder steps, animation, reveal
- `src/content/*.json` — owner-editable data (flowers, greenery, presentation, occasions, card fonts) — see `docs/content-editing-guide.md`
- `src/assets/svg/` — hand-authored flower/greenery/presentation art — see `docs/flower-art-guide.md`
- `src/lib/kv.ts` — storage adapter for share links; **ships as in-memory, needs a real KV swap before launch** (see `docs/architecture.md`)
- `tests/unit/` (Vitest), `tests/e2e/` (Playwright)
- `docs/` — architecture, state schema, content editing, flower art conventions
- `assets/` — reference-only brand assets + inspiration screenshots, not shipped (see `src/assets/svg/` for shipped art)

## Working conventions
- Keep `src/builder/*` framework-free plain TypeScript — no React/Svelte/Vue.
- Colors/fonts are CSS custom properties in `src/styles/tokens.css`; flower art uses `var(--bloom-fill)` etc. so species stay themeable without hardcoded colors baked into SVGs.
- `BouquetState` (`src/builder/state/schema.ts`) is the single source of truth shape for both the URL-encoded token and the server-stored record — keep them in sync; bump `SCHEMA_VERSION` on breaking changes.
- The four builder steps + the recipient reveal all render bouquets through `composePresentedBouquet.ts` (or `renderPlacements.ts` directly) — don't duplicate composition logic in a step file.
- Cream-paper-and-purple-ink is the fixed brand identity, not a light/dark theme — it does not respond to `prefers-color-scheme`.

## Commands
- `npm install && npm run dev` — local dev server (http://localhost:4321)
- `npm run build` — production build
- `npm test` — unit tests
- `npm run test:e2e` — Playwright E2E (auto-starts a dev server)
- `npm run check` — Astro/TS diagnostics
